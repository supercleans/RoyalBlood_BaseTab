🚀 무료 서버(0원)에 올려서 언제든 보는 방법

이 웹앱은 별도 백엔드나 DB 과금 없이 단일 HTML 파일 1개로 동작하므로, 보유하신 GitHub 계정(supercleans)의 GitHub Pages에 올리면 서버비 평생 0원으로 전용 웹 주소를 만들 수 있습니다.

# 1) 상단 [💾 index.html 다운로드] 버튼으로 파일을 저장한 뒤 폴더에서 실행: mkdir bass-tabs && mv ~/Downloads/index.html bass-tabs/index.html cd bass-tabs git init git branch -M main git add index.html git commit -m "Add Dual-Chain Bass Tab Studio v4 Web App" git remote add origin https://github.com/supercleans/bass-tabs.git git push -u origin main

웹 브라우저만으로 올리기 (Git 명령어 없이):
1) GitHub에서 새 Public 저장소(예: bass-tabs)를 생성합니다.
2) 상단 💾 index.html 다운로드 버튼을 눌러 받은 index.html 파일을 저장소에 업로드(Add file → Upload files)합니다.
3) 저장소의 Settings → Pages → Branch를 main / /(root)로 지정하고 Save를 누르면 1분 뒤 https://supercleans.github.io/bass-tabs/ 주소가 활성화됩니다.

Git 저장소를 만들거나 공개하기 싫다면 Cloudflare Pages Direct Upload가 가장 빠릅니다. 트래픽 무제한 무료이며 비공개 개인 링크처럼 쓰기 좋습니다.

1) 상단 [💾 index.html 다운로드] 버튼을 클릭해 index.html 파일을 저장합니다. 2) 새 폴더(예: my-bass-tabs) 안에 방금 받은 index.html 파일을 넣습니다. 3) Cloudflare 대시보드 → Workers & Pages → Create → Pages → [Upload assets] 선택! 4) 프로젝트 이름(예: my-bass-tab) 입력 후 폴더를 드래그 앤 드롭하면 10초 만에 https://my-bass-tab.pages.dev 주소가 생성됩니다.

배포된 URL을 스마트폰(갤럭시 S25 등)이나 태블릿에서 열면 네이티브 앱처럼 전체화면 아이콘으로 등록할 수 있습니다.

• Android (Chrome / 삼성 인터넷): 배포된 주소 접속 → 우측 상단 메뉴(⋮) → [홈 화면에 추가] • iPad / iPhone (Safari): 배포된 주소 접속 → 공유 버튼(□↑) → [홈 화면에 추가] • 곡별 바로가기 링크: 주소 뒤에 #ten-tonne-skeleton, #figure-it-out, #feel, #gasoline 이 자동으로 붙어 특정 곡 링크만 바로 열 수도 있습니다.
